Before you start

You do not need to know how to code to use this system. If you can open a folder and type a sentence, you can run the workflow. This guide walks you through every step.

Section 1

What the system does

The UV AI Workflow is a purpose-built decision engine. It replaces hours of manual research with a structured, repeatable process that enforces Unconventional Ventures' investment criteria automatically.

🔍
Sourcing Workflow

You ask the AI to find startups. It searches the web, verifies sources, applies UV's investment criteria, and delivers only deals worth your time — typically killing 70–80% before they reach you.

📋
Due Diligence Workflow

You provide information about a specific startup. The AI runs 8 analytical agents in sequence — from founder evaluation to a falsification test — and returns a final invest/pass decision.

How it thinks

The system operates on one core principle: default is PASS. A deal must earn its way forward. The AI is not trying to find reasons to invest — it is trying to find reasons to eliminate a deal as fast as possible.

This mirrors how elite VC funds actually work. The question is never "could this be good?" It is: "Is there anything here that would stop us from investing?"

What the AI prioritises

  • Real customer revenue (not press or awards)
  • Underrepresented founders (women, POC, immigrants)
  • Specific unfair advantages (not generic claims)
  • Impact that solves systemic problems
  • Stage fit (pre-seed or very early seed)

What the AI ignores

  • Press coverage and awards
  • "AI-powered" descriptions without proof
  • Pilot announcements without contracts
  • Generic market size claims
  • Storytelling without data

The fund context it applies automatically

Every run — sourcing or due diligence — automatically applies UV's fund mandate. You never need to remind it. These constraints are built in:

CriterionRequirement
StagePre-seed or very early seed only
Total funding raisedMaximum €5M — above this is an automatic kill
Check sizeUV must be able to lead or be first institutional check
Round size€500K – €3M target range
GeographyNordics (SE, DK, NO, FI) first; also UK, Germany, Spain
FoundersUnderrepresented background — near-required (women, POC, immigrants, LGBTQ+)
Existing backersMust NOT already be backed by Sequoia, Index, Balderton, Planet A, byFounders, Atomico, EQT, CDP, TDK, or equivalent
Section 2

What you need to install

You need three things: Node.js (a background software engine), Claude Code (the AI interface), and an Anthropic API key (your access credential). Each step takes about 5 minutes.

Time required

First-time setup takes approximately 15–20 minutes. Subsequent use on the same computer requires no setup at all.

Step 1 — Install Node.js

Node.js is a piece of background software that Claude Code requires to run. You won't interact with it directly — it just needs to be present on your computer.

1
Go to nodejs.org

In your browser, visit nodejs.org and click the large green button labelled "LTS" (Long Term Support). This downloads the installer.

2
Run the installer

Open the downloaded file and click through the installation steps. Accept all defaults. No customisation needed.

3
Verify it worked

Open your Terminal (Mac) or Command Prompt (Windows) and type the following, then press Enter:

node --version

You should see a version number like v22.x.x. That means it worked.

Step 2 — Install Claude Code

Claude Code is the AI interface. It runs in your Terminal or Command Prompt — a plain text window where you type instructions. There is no app to open separately.

1
Open your Terminal or Command Prompt

Mac: Press Command + Space, type "Terminal", press Enter.
Windows: Press the Windows key, type "Command Prompt", press Enter.

2
Type the install command

Copy and paste the following exactly as written, then press Enter:

npm install -g @anthropic-ai/claude-code

Wait for it to finish. You will see text scrolling — this is normal. It takes about 1–2 minutes.

3
Verify it worked

Type the following and press Enter:

claude --version

You should see a version number. If you do, Claude Code is installed.

Step 3 — Get your Anthropic API Key

An API key is a private password that lets Claude Code access the AI. Each team member needs their own.

1
Go to console.anthropic.com

Create an account or log in if you already have one.

2
Create an API key

Navigate to API Keys in the left sidebar. Click "Create Key". Give it a name (e.g. "UV Workflow"). Copy the key — it starts with sk-ant-.

3
Add billing

Go to Billing and add a payment method. A typical sourcing run costs less than $0.50. Due diligence runs cost $0.50–$2.00.

4
Connect the key to Claude Code

In your Terminal, type:

claude # This launches Claude Code for the first time

It will ask for your API key. Paste it and press Enter. You only do this once per computer.

Keep your API key private

Treat your API key like a password. Do not share it, post it in emails or documents, or store it in shared folders. Each team member should have their own key.

Section 4

Running a Sourcing workflow

The Sourcing workflow finds new startups and evaluates whether they are worth entering the UV pipeline. It runs 6 AI agents in sequence and delivers 2 vetted candidates per run.

How to trigger it

Once Claude Code is running, simply type a message containing one of these phrases:

"find startups"

The AI recognises this phrase and automatically launches the Sourcing workflow.

"search"

Any message containing "search" will also trigger the Sourcing workflow.

Example prompts you can type

find startups in climate tech in the Nordics
search for impact-driven B2B SaaS founders in the UK
find startups in financial inclusion — diverse founders only
run sourcing for healthcare access startups in Sweden or Denmark
You can be specific or general

If you specify a sector or geography, the AI will focus there first. If you are vague, it applies UV's default criteria. Either way, all hard kill rules are always enforced.

What the AI does next (automatically)

After you type your message, the AI runs 6 agents in order. You will see the output appear progressively. This takes approximately 3–8 minutes per run.

→
02Source Checker
→
03Signal Extractor
→
04Kill Agent
→
05Thesis Fit
→
06Decision
AgentWhat it does
Scouter Searches the web for matching startups. Max 3 queries per company. Must find at least one funding signal and one structural source (website/LinkedIn).
Source Checker Verifies every factual claim. If a claim cannot be verified, it is marked "unknown" — not assumed true.
Signal Extractor Identifies the startup's unfair advantage (founder edge, technical breakthrough, distribution access, or real traction). Rejects narrative-only companies.
Kill Agent Applies all hard kill rules. If any condition is triggered, the startup is eliminated immediately and replaced with a new search. This agent's decision cannot be overridden.
Thesis Fit Scores alignment with UV's specific mandate: diverse founder, geography, stage, B2B impact-primary.
Decision Outputs one of three verdicts: Advance — strong signals, proceed to DD. Track — interesting but not ready. Pass — weak or killed.

Saving the output

Ask the AI to save results before ending the session:

save this sourcing run as outputs/sourcing_run_11.json

This stores the full structured output in the outputs/ folder for future reference and due diligence runs.

Section 5

Running a Due Diligence workflow

The Due Diligence workflow takes a specific startup and runs it through 8 analytical agents, ending in a binary invest/pass decision. It uses only the information you provide — it does not search the web.

How to trigger it

Type a message containing one of these phrases:

"analyze"

Triggers the Due Diligence workflow.

"evaluate" or "due diligence"

Either phrase launches the full DD process.

What information to provide

Give the AI as much detail as you have. The more specific you are, the better the analysis. Minimum required:

Example DD prompt

Analyze this startup:

Name: Cogs AI
Description: AI mental health support for neurodivergent people (ADHD, autism). NHS contract renewed. 15,000 patients. 30% improvement in outcomes at 2 weeks. 4x usage vs NHS baseline.
Stage: Pre-seed
Location: London, UK
Founders: Zareen Ali (CEO, autistic, Harvard MSc Educational Neuroscience, ex-medical tech PM). Felix de Grey (Co-founder).
Total raised: £650K (Bethnal Green Ventures, Innovate UK)
Market: NHS mental health backlog 1.8M. ADHD diagnosis wait 3–5 years. 1 in 7 people neurodivergent.
Traction: NHS contract renewed post-impact evaluation. 15,000+ patients. No disclosed ARR.

On missing information

If you don't have certain data (e.g. ARR is undisclosed), include that in your prompt. The AI marks gaps as "unknown" and treats missing information as a negative signal, not neutral. This is intentional — it prevents false confidence from incomplete data.

Section 6

Reading the outputs

The AI outputs results in JSON format — a structured data format that looks technical but follows a simple logic. Here is how to read it without any coding knowledge.

What is JSON?

JSON is like a structured form. Every piece of information has a label (called a "key") and a value. For example: "decision": "pass" means the "decision" field contains the value "pass". You read left-to-right: label, then result.

Sourcing output — key fields to read

FieldWhat it meansValues
kill_decision Did the startup pass the hard kill rules? proceed or kill
traction_signal Quality of real commercial evidence found strong / weak / none
unfair_advantage The specific edge identified (or "none") Text description
uv_fit How well the startup aligns with UV's mandate high / medium / low
decision The final sourcing recommendation advance / track / pass

Due Diligence output — key fields to read

FieldWhat it meansValues
decision The investment recommendation invest or pass
conviction How strongly the AI holds the decision high / medium / low
one_line_verdict The single most important reason for the decision — always read this first Plain English sentence
must_answer_questions The specific questions you need answers to before reconsidering List of questions
most_likely_failure If this startup fails, what breaks first? Plain English sentence
why_this_fails A list of plausible failure scenarios List of reasons

Understanding a PASS decision

A PASS does not always mean "bad company". It can mean:

  • Revenue opacity: The company may be doing well, but ARR is undisclosed. The AI cannot confirm commercial viability without numbers.
  • Stage mismatch: Too advanced or too early for UV's check size.
  • Fund mandate mismatch: Great company, wrong fund (e.g. clinical-stage medtech requiring €10M+).
  • Re-engage trigger: Most PASS decisions include a specific condition under which to revisit (e.g. "Re-engage when ARR ≥ £150K disclosed").
  • Impact gap: Strong founders but no genuine systemic impact thesis — generic B2B tool.
  • Traction too weak: Pilots, press, and partnerships do not qualify as traction.
Section 7

The pipeline rules

The AI enforces a set of hard rules on every run. Understanding these helps you craft better prompts and interpret why a company was killed. These rules evolved through 10 real sourcing runs.

Hard kill rules — any one triggers an automatic KILL

  • Total funding raised exceeds €5M
  • Already backed by a tier-1 VC (Sequoia, Index, Balderton, Planet A, byFounders, CDP, TDK Ventures, Atomico, EQT Ventures)
  • Round is oversubscribed with corporate strategic investors
  • Outside target geographies (Nordics: SE, DK, NO, FI — plus UK, Germany, Spain)
  • Founding team shows no underrepresented background (all-male, all-white) — unless an extraordinary exception is clearly documented
  • No clear unfair advantage identifiable
  • Traction signal is completely absent
  • Problem is not urgent
  • Product is indistinguishable from alternatives
  • Company is purely narrative-driven with no data

Excluded sectors (do not source these)

These sectors have been permanently excluded from UV's pipeline following due diligence learnings across 10 runs:

Excluded SectorReason
Clinical-stage medtech / EU MDR devicesCapital requirement (€10M+) exceeds seed fund mandate
Menopause / women's health digital health (DiGA)Regulatory certification cost structure incompatible with seed stage
Consumer CPG / B2C sustainability brandsDifferent unit economics and distribution to UV's B2B mandate
Social AI / HCI infrastructure layersImpact measurement and B2B revenue model unclear
AI conveyancing / proptech legal automationRegulatory liability risk + capacity ceiling identified in DD
Fashion fit technologyB2C-adjacent; revenue opacity pattern; no differentiation vs. incumbents
FP&A / financial planning SaaSGeneric B2B tool; no impact thesis; severe competitive density
AI sales automationGeneric B2B tool; no systemic impact; crowded market

What "traction" actually means

This is the most commonly misunderstood rule. The system classifies traction strictly:

Strong traction

Verified revenue or signed commercial contracts only. Nothing else qualifies.

Weak traction

Letters of Intent (LOIs) or pilots with defined commercial intent and a timeline to convert.

  • Press coverage — does not count
  • Awards or rankings — does not count
  • Investor announcements — does not count
  • Partnership announcements without contract terms — does not count
  • Unnamed enterprise customers — does not count
  • Pilot programmes without commercial commitment — does not count
Why this matters

Revenue opacity — where a company has paying customers but does not disclose ARR — is the number one reason due diligence ends in PASS. Across 10 runs, every PASS decision at DD stage was driven at least partly by undisclosed revenue figures. The single most important question to answer before a DD run is: what is the company's ARR?

Key patterns learned across 10 runs

Run 4: Stage and portfolio fit constraints added

Initial runs found companies with €10M–€27M raised and tier-1 VC backing. Hard kill rules were added: €5M cap, no tier-1 VCs, geography list, diverse founder requirement.

Run 6: Sector exclusions begin

Clinical medtech and menopause digital health added to excluded sectors after DD revealed capital requirements incompatible with UV's mandate.

Run 8: Revenue opacity identified as primary DD failure mode

Companies with credible founders, named clients, and right stage were consistently PASSed because ARR was undisclosed. This is a data access problem, not a business quality problem.

Run 10: Impact filter moved upstream to sourcing

Most important system change. Previously, impact screening only happened at DD — causing wasted cycles on strong founders building generic B2B tools. Now impact verticals are targeted from the first sourcing query. Both Run 10 companies had genuine primary impact theses.

Section 8

Sharing with teammates

Anyone on the team can run this workflow on their own computer. All they need is the project folder, a Claude Code installation, and their own API key.

Checklist for a new team member

  • Install Node.js from nodejs.org (accept all defaults)
  • Install Claude Code: npm install -g @anthropic-ai/claude-code
  • Create a personal Anthropic API key at console.anthropic.com
  • Add billing to the Anthropic account (pay-per-use, very low cost)
  • Run claude once to connect the API key
  • Clone or copy the project folder onto their computer
  • Navigate to the project folder in Terminal and run claude

Keeping outputs in sync

If multiple team members are running the workflow, they should regularly sync their outputs/ folder so everyone has the same pipeline history.

↕
Via GitHub (recommended)

If the project is on GitHub, team members run git pull to get the latest outputs and git push after saving new runs.

☁
Via shared cloud folder

Store the project folder in a shared Google Drive or Dropbox. Each team member works from the same folder. Avoid running simultaneous sessions on the same files.

Section 9

Frequently asked questions

Do I need to know how to code to use this?
No. If you can open a Terminal window and type a sentence, you can run the workflow. The most technical step is typing npm install -g @anthropic-ai/claude-code once during setup.
How much does it cost to run?
A typical sourcing run costs under $0.50. A full due diligence run costs $0.50–$2.00. Costs are charged per-use directly to your Anthropic account — there is no monthly subscription for the workflow itself.
Why does the AI kill most startups it finds?
This is by design. The system is calibrated to eliminate 70–80% of companies. UV's fund mandate is highly specific: pre-seed, €5M cap, diverse founders, impact-primary B2B, Nordics and select European geographies. Most startups found in a broad search will fail one or more of these criteria. Strict elimination means only genuinely aligned deals reach you.
Can I add new sectors to exclude?
Yes. Open the prompts.md file and add the sector to the "EXCLUDED SECTORS" list. Also add it to docs/agents.md in the Kill Agent section. The AI will apply it in all future runs.
What if the AI finds a startup that doesn't exist?
The system requires the AI to verify every claim from real web sources. If it cannot find at least one funding/investor signal and one structural source (website or LinkedIn), the startup is marked as unverified and killed. Fabricated companies should not pass the Source Checker. If you suspect a result is invented, ask the AI to show its sources.
Can I run DD on a startup that wasn't found through sourcing?
Yes. The sourcing and due diligence workflows are independent. You can run DD on any startup by providing its details directly. This is useful for inbound deal flow or warm introductions.
The output is JSON and I find it hard to read. What do I do?
After the JSON output appears, simply ask: "summarise this in plain English". The AI will provide a human-readable version. Alternatively, focus on the one_line_verdict field in DD outputs and the decision field in sourcing outputs — these give you the key result immediately.
Can I change the fund geography or stage criteria?
Yes, but do so carefully. Open CLAUDE.md and docs/agents.md and update the relevant sections. Changing geography or stage criteria affects the Kill Agent and will change which companies survive sourcing runs. Ensure any changes are agreed by the fund before editing.
How do I know the AI isn't just making up its analysis?
The system has explicit anti-hallucination rules: every claim must come from a verified source, unknown information must be labelled "unknown" rather than assumed, and the AI is forbidden from softening judgements based on incomplete data. You can always ask "what are your sources for this?" to see the evidence behind any claim.
What happens to the outputs after a session ends?
Nothing is saved automatically. You must explicitly ask the AI to save results: "save this as outputs/sourcing_run_12.json". If you close the Terminal without saving, the session output is lost. Make saving the last step of every session.
Can I share the API key with a colleague?
Technically possible but not recommended. Sharing API keys makes it hard to track usage and control costs. Each team member should create their own free API key at console.anthropic.com. It takes 2 minutes.
Questions not covered here?

If you encounter an issue not covered in this guide, ask the AI directly inside the session. Type your question and it will help you troubleshoot. Claude Code also has built-in help accessible by typing /help.
